If you find Kairo useful and would like to support its development, you can donate cryptocurrency using one of the addresses below.

* Documentation
* Development tools and services
* Testing
* Future Kairo features

## 🌐 Other Networks

Additional cryptocurrencies and networks may be added in the future.

When adding a new address, always verify:

1. The cryptocurrency
2. The network
3. The address
4. That the wallet supports the selected network

Sending funds over the wrong network may result in permanent loss of funds.

## 🔐 Address Verification

Official Kairo donation addresses will only be published through the project's official repository and official project documentation.

**Never trust a donation address sent to you privately unless it can be independently verified against the official Kairo repository.**

If you believe an address in this file has been compromised or replaced, please report the issue through the project's official security reporting process.
